# Agent 招聘评估台

面向 **Agent 工程实习** 招聘的本地评估台：简历筛选、批次管理、面试进度看板、定制面试题。

## 适用角色

| 角色 | 常用能力 |
|------|----------|
| HR / 面试官 | 网页上传简历、看板拖拽改状态、查看 S 档面试题与参考答案 |
| 开发 / Cursor | REST API、`scripts/hub` CLI、批量 `/api/screen` |
| 运维 | `make deploy` 部署到 mirror_zby |

## 招聘标准（内置）

要 **上手就能干活** 的 Agent 工程实习生。详细说明见知识库「[用人标准](?tab=docs#hiring)」。

1. **聪明度与潜力** — 苗子，能自己发现真问题并给出可验证改法  
2. **广度与深度** — 有一定广度，且至少一条线能追到实现与失败路径  
3. **工程意识** — 对耗时/P99/失败敏感（例如「检索飙到 20 秒」会当故障来修）  

硬门槛：真实实习 + 项目上线。自动评分见 `scoring_prompt.txt`；**图片 PDF 可能不准**，以人工档位和简历为准。
