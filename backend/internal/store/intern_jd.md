# Agent 工程实习生

要 **上手就能干活** 的人：进组第一周能跟现有代码、线上问题和评测动手，不是背 LangGraph / RAG 名词。

## 岗位职责

- 参与 Agent 工程落地：工具调用、检索、评测、线上问题
- 能独立跟一块代码改到可验证（有数字或 bad case）
- 对延迟、正确性、失败路径敏感，把「检索飙到 20 秒」当事故修

## 我们要什么样的人

| 维度 | 要什么 | 不要什么 |
|------|--------|----------|
| **聪明度与潜力** | 能自己发现真问题、拆开、给出可验证的改法 | 只会复述简历；数字经不起问 |
| **广度与深度** | 有一定广度，且至少 1 条线能追到实现与失败路径 | 技能表很长但每个项目只到 pipeline 介绍 |
| **工程意识** | 对耗时 / P99 / 超时 / 重试 / 幂等敏感 | 对「十几秒」无感觉；讲不清 owner |

**硬门槛：** 真实公司实习 + 项目上线/生产落地。仅校内或个人项目、实习无上线描述，默认不够。

## 加分

- 工程意识有前后对比：检索 20s→5s、上下文压缩、P99 下降、压测写出并发
- 在已上线的 Agent / 业务后端里独立负责一块并交付
- 一条链路能讲完：问题发现 → 方案 → 验证 → 上线

## 档位（评估台）

| 档位 | 条件 |
|------|------|
| **S** | 上手就做 + 三维都有证据；最好有耗时/失败/量级闭环 |
| **A** | 苗子明显但实习偏短/无上线，或三维里一维弱 |
| **淘汰** | 无实习落地；或纯名词；或对延迟/失败无意识 |

上传简历时按本岗绑定的检验标准自动评分；面试以简历原件和人工档位为准。
